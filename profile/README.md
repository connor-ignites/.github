## Connor Ignites

I make games, and the tools I need to make them. When a tool turns out useful beyond my own projects, it ends up here, free and open source.

**[GaitKeeper](https://github.com/connor-ignites/gaitkeeper)** is a Blender add-on that checks game animation clips for sliding feet, pops, backward knees and other motion faults, on people and on animals. It only ever writes fixes to a copy of your clip. It's in beta, and bug reports with the rig attached help the most.
